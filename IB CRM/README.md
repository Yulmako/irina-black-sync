# Синхронизация записей zapis.kz → CRM

Этот маленький проект раз в час сам заходит в ваш кабинет zapis.kz (используя
сохранённую сессию) и складывает свежие записи в `data/bookings.json`. Дальше
я (Claude) забираю этот файл раз в час и обновляю вашу CRM-панель — без
участия вашего компьютера.

Ничего из этого не проходит через меня, кроме самого файла с записями:
ваш пароль и SMS-код вы вводите только на сайте zapis.kz, а токен доступа
(cookie) вы сами копируете и вставляете в настройки GitHub — я его не вижу
и не храню.

## Шаг 1. Создайте бесплатный аккаунт на GitHub

Если аккаунта ещё нет — зарегистрируйтесь на [github.com](https://github.com)
(бесплатно, займёт пару минут).

## Шаг 2. Создайте приватный репозиторий

1. Нажмите **New repository**.
2. Имя — например `irina-black-sync`.
3. Обязательно выберите **Private**.
4. Создайте репозиторий.

## Шаг 3. Загрузите файлы этого проекта

В новом репозитории нажмите **Add file → Upload files** и перетащите туда
всю папку `zapis-sync` целиком (структура папок — `.github/workflows/sync.yml`,
`scripts/sync.js`, `data/bookings.json` — должна сохраниться). Подтвердите
коммит.

## Шаг 4. Скопируйте cookie-токен своей сессии

Это самый важный шаг — именно он заменяет собой пароль.

1. Откройте [zapis.kz](https://zapis.kz/partner/f/0/main) в браузере и
   убедитесь, что вы вошли в свой кабинет.
2. Откройте инструменты разработчика (клавиша **F12**, или правая кнопка
   мыши → «Просмотреть код») и перейдите на вкладку **Network** (Сеть).
3. Обновите страницу (F5). В списке запросов найдите любой к адресу,
   начинающемуся с `reservation/list` или `masters-list`, и кликните на него.
4. Справа откройте **Headers → Request Headers** и найдите строку,
   начинающуюся с `Cookie:`. Скопируйте **всё**, что идёт после `Cookie: `
   (это длинная строка) — это и есть ваш токен сессии.

## Шаг 5. Вставьте токен в секреты GitHub

1. В репозитории откройте **Settings → Secrets and variables → Actions**.
2. Нажмите **New repository secret**.
3. Имя: `ZAPIS_COOKIE`.
4. Значение: то, что скопировали в шаге 4.
5. Сохраните.

## Шаг 6. Запустите первую синхронизацию вручную

1. Откройте вкладку **Actions** в репозитории.
2. Слева выберите **Sync zapis.kz bookings**.
3. Нажмите **Run workflow → Run workflow**.
4. Через минуту-другую откройте запуск и убедитесь, что он завершился
   зелёной галочкой, а в файле `data/bookings.json` появились ваши записи.

Если запуск закончился красным крестиком — скорее всего, что-то не так со
значением `ZAPIS_COOKIE` (проверьте, что скопировали строку целиком, без
переносов строк и без слова `Cookie:` в начале).

С этого момента синхронизация будет запускаться сама, каждый час, по
расписанию (`cron` в `.github/workflows/sync.yml`) — компьютер и приложение
Claude для этого не нужны.

## Шаг 7. Дайте мне доступ на чтение (только чтение, только этот файл)

1. Откройте **Settings своего профиля** (аватар в правом верхнем углу →
   Settings) → **Developer settings** → **Personal access tokens** →
   **Fine-grained tokens** → **Generate new token**.
2. **Repository access** → **Only select repositories** → выберите
   `irina-black-sync`.
3. **Permissions → Repository permissions → Contents** → **Read-only**.
   Больше ничего не включайте.
4. Сгенерируйте токен и скопируйте его.
5. Пришлите мне в чат: сам токен + имя репозитория (например,
   `ваш-логин/irina-black-sync`).

Токен даёт доступ только на чтение и только к этому одному репозиторию —
его в любой момент можно отозвать в тех же настройках GitHub.

После этого я настрою свою часть — автоматическое обновление CRM-панели
раз в час из этого файла — и синхронизация заработает полностью сама,
без вашего компьютера.

## Если синхронизация вдруг остановится

Сессия (cookie) рано или поздно истечёт — заранее неизвестно, через сколько
времени. Когда это случится, запуск в GitHub Actions начнёт завершаться с
ошибкой, и GitHub автоматически пришлёт вам письмо на почту с темой вроде
«Run failed». Это и есть сигнал повторить шаги 4–5 (скопировать новый
cookie и обновить секрет `ZAPIS_COOKIE`) — обновление панели тут же
возобновится.
